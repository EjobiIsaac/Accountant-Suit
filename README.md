Bookkeeping + Invoicing (VAT 18%) + Payroll (PAYE + NSSF + LST) + Reports / Tax

- General Ledger - Double Entry
- Invoices with VAT 18% & Withholding 6%
- Payroll: URA PAYE, NSSF 5%/10%, LST
- Reports: Profit & Loss, Trial Balance, Balance Sheet, VAT Report
- Clients Management

- Offline - No Internet Needed
